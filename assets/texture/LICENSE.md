# Texture sources

All textures in this directory are **CC0 1.0 (public domain)** — no
attribution required, commercial use permitted, no restrictions.

Downloaded from [ambientCG](https://ambientcg.com) (1K JPG variants).
Only the colour and OpenGL-convention normal maps are kept; displacement,
roughness and the .blend/.usdc scene files were discarded to keep the
repository small.

| File | Source material | Use |
|---|---|---|
| `runway_asphalt_*`   | Asphalt013     | Runway surface |
| `apron_concrete_*`   | Concrete034    | Apron and taxiway |
| `airfield_grass_*`   | Grass004       | Ground around the runway |
| `fuselage_panel_*`   | MetalPlates006 | Aircraft skin detail |

Each is seamlessly tileable and power-of-two sized, as required by the RSX.
